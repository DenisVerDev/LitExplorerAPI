# LitExplorer API
REST API application that handles all backend functions of the federated search platform LitExplorer.

Part of the [**LitExplorer**](https://github.com/DenisVerDev/LitExplorer) project and my bachelor thesis.

See screenshots folder for an image of some of the endpoints.

## Technologies
- .NET 8.0
- BCrypt.Net
- EntityFrameworkCore
- Microsoft.ML
